# Project Guidelines

## Tailwind CSS v4 Conventions
- This project uses Tailwind CSS v4.
- Do not use arbitrary value syntax with brackets when a native v4 utility exists:
  - Write `z-100` instead of `z-[100]`.
  - Prefer native numerical utility classes (e.g. `z-100`, `w-4.5`, `max-w-35`) over bracketed arbitrary syntax like `z-[100]`, `w-[18px]`, `max-w-[140px]`.
